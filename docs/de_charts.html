💡 关键发现：wire_load_mode 对本设计 QoR 影响极小（面积/功耗差异 < 0.1%），但对编译时间影响显著。 E3 enclosed 模式最快（132.8s），比 E1 default 快 21%；E4 segmented 功耗最低（7.82 mW）。 本设计模块层次扁平（picorv32 核心），连线延迟占比低，wire_load_mode 优化空间有限。推荐使用 enclosed 模式，兼顾编译速度和优化质量。

🗺️ D 组结论（Pareto 图）

🏆 E 组推荐

E3 enclosed 是最优选择：
  • 编译时间最短（132.8s，比 default 快 21%）
  • 时序、面积、功耗与其他模式无差异
  • enclosed 模式符合层次化设计理念

D 组结论：
  • set_max_area 对时序 clean 的设计无效
  • 本设计最小面积 ~72K µm²（Nangate45nm）
  • 降面积需降频或删减逻辑
