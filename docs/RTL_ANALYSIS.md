# RTL Analysis Report - picosoc

## 1. 模块层次结构

| 模块 | 行数 | 说明 |
|------|------|------|
| picorv32.v | 3049 | RISC-V CPU 核，RV32I + MUL/DIV |
| picosoc.v | 262 | SoC 顶层，集成 CPU + 外设 |
| spimemio.v | 579 | SPI 内存接口控制器 |
| simpleuart.v | 137 | 简单 UART（无 FIFO） |
| spiflash.v | 409 | SPI Flash 模型（已修复，移除 #1 延迟） |

**顶层模块**: `picosoc`
**顶层端口**: clk, resetn, irq_5/6/7, ser_tx/rx, flash_*, iomem_*

## 2. 时钟域分析

| 项目 | 值 |
|------|-----|
| **主时钟** | clk, 单一频率 |
| **时钟分频/PLL** | 无 |
| **时钟 mux** | 无 |
| **跨时钟域** | irq_5/6/7（异步输入，未见同步器） |

**100MHz 可行性：**

| 频率 | 结论 | 依据 |
|------|------|------|
| **50 MHz** | ✅ 可行 | CPU 核心路径 (~8ns) << 20ns 周期 |
| **100 MHz** | ⚠️ 有风险 | 核心路径 (~8ns) ≈ 10ns 周期，slack 仅 ~2ns |

## 3. 复位策略

- **resetn**: 异步低有效复位
- **复位域**: 单一复位域（所有模块共用 resetn）

## 4. 资源统计

| 模块 | 寄存器数 | 状态机 |
|------|---------|--------|
| picorv32 | ~110 | 1 (cpu_state) |
| picosoc | 3 (irq, ram_ready) | 0 |
| simpleuart | 10 | 2 |
| spimemio | ~48 | 2 |
| **总计** | **~171** | **5+** |

**RAM**: `picosoc_mem` 分布式 RAM（256×32bit，综合为触发器阵列）

## 5. 关键路径预估

**最坏路径**: CPU 执行单元 → 内存访问 → 外设接口

**时序分析**:
- Picorv32 单周期指令路径: ~4-6ns → **50MHz 完全可行**
- 多周期指令（MUL/DIV）: 32-64 周期，不影响时钟频率
- SPI Flash 访问: 可变等待周期，是 100MHz 主要风险

## 6. 已知问题

| 问题 | 严重性 | 说明 |
|------|--------|------|
| `spiflash.v` #1 延迟 | 🔴 已修复 | 已移除，不可综合 |
| irq_5/6/7 异步 CDC | ⚠️ 需处理 | 建议加 2 级同步器 |

## 7. 综合建议

1. **排除 `spiflash.v` 中的延迟语句** — 已修复
2. **irq 信号加同步器** — 或 set_false_path 处理
3. **50MHz 作为首次综合目标** — 保守但稳妥
4. **100MHz 作为挑战目标** — 视 50MHz 综合结果决定
