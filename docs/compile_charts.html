⚡ gate_clock 效果惊人

启用 -gate_clock 动态功耗降低 5.7 倍（7.91 vs 44.84 mW）。无门控时所有寄存器每周期翻转，clock tree 功耗暴涨。

🏛️ autoungroup 无实质收益

B vs A：面积几乎相同（+0.06%），LoL 仅减少 1，编译时间反而增加 35%。但模块层次被破坏（Hierarchical Cell Count 从 1112→7）。

🔋 功耗是最大差异

C 无门控时漏功耗也高出 17%（1.53 vs 1.30 mW），Hold violations 多 2 倍（1493 vs 755），整体健壮性最差。

⚠️ 重要结论：不要关闭 clock gating -gate_clock 是 DC 降低功耗最重要的选项之一。对 picosoc 这类移动/嵌入式处理器设计，44.84 mW vs 7.91 mW 的差距在实际应用中非常关键。
no_autoungroup 保留模块层次，便于后续 debug 和 timing analysis，收益大于成本（+46s 编译时间）。
